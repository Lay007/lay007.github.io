# Research and Engineering Focus

This site presents an engineering portfolio focused on reproducible DSP and communication-system development.

## Main directions

| Area | Focus |
|---|---|
| DSP | deterministic signal-processing pipelines |
| FPGA | streaming RTL architectures |
| SDR | end-to-end RF experimentation |
| Optical DSP | coherent receiver processing |
| Measurement systems | latency, jitter and SLA analytics |

## Engineering methodology

```text
model
-> implementation
-> fixed-point
-> FPGA
-> measurement
-> report
-> reproducibility
```

## Engineering principles

- reproducible experiments;
- explicit metrics;
- shared datasets;
- deterministic validation;
- publication-oriented visualization.
